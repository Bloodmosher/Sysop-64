How to think about the curve

The curve maps the SID cutoff register to the effective filter cutoff used by the active SID core. The horizontal axis is labeled like the usual SID reference plots, using the full 11-bit cutoff code from $D415/$D416. The editable FPGA table is still 1024 entries: bucket N is used for SID cutoff codes 2N and 2N+1. Higher points sound brighter because more high frequencies pass through the filter. Lower points sound darker or more muffled. The SID model selector switches the SID core between its 6581 and 8580 behavior, and the volume control changes the HDMI SID output level without changing the table.

  • Move a region up to brighten instruments that use those cutoff values.
  • Move a region down to darken or soften them.
  • Move the rising knee left when low and middle cutoff settings feel too muffled.
  • Move the rising knee right when too much of the filter range opens too early.
  • A steeper curve makes filter sweeps more dramatic over a smaller register range.
  • A flatter curve makes sweeps more gradual and forgiving.

The yellow markers show a few SID-Wizard-style filter-table test points, such as 90 10, 90 80, 90 C0, and 90 F0. Those markers are placed at approximately cutoff-byte << 3 on the native SID cutoff scale. If one test sounds wrong, edit near that marker first, then upload the whole curve or keep dragging for realtime changes.
